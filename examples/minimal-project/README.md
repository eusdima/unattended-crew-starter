# Minimal project

A two-page static site with one deliberate bug: the footer link on `index.html` points to `/contct` instead of `/contact`.

Copy this folder somewhere outside this repository, run `git init`, push it to a new GitHub repository of your own, and add that repository to your first mate. Then ask for the link to be fixed.

```text
minimal-project/
├── README.md
├── index.html
└── contact.html
```
